# הכח שבי — מערכת לכיתה אחת

מערכת ניקוד כיתתית למחנך ולמורים המלמדים באותה כיתה. אין כאן נתונים מבית הספר או משנת הלימודים שעברה.

## מה יש במערכת

- כניסה למחנך ולמורים נוספים של אותה כיתה
- ניקוד כיתתי לפי שיעורים (0–3), כמו בטבלה המוכרת
- חנות כיתתית על נקודות הכיתה
- רישום מצטיינים בשיעור — בלי נקודות אישיות ובלי חנות אישית
- גלגל מזל אקראי בין המצטיינים (או בין כל הכיתה)
- הערות להורים מרשימה כיתתית, עם שליחה בוואטסאפ
- חלונית שיעור קטנה: רק עמודת שיעורי היום, בלי מסגרת, לשימוש במקביל לשיעור
- עובד גם מהטלפון (אפשר להתקין למסך הבית)

## התחלה

1. פתחו את `index.html` בדפדפן (או העלו את התיקייה לאירוח סטטי).
2. בפעם הראשונה: «הקמת כיתה חדשה» — שם כיתה, שם מחנך, סיסמה, ורשימת תלמידים.
3. בניהול הכיתה אפשר להוסיף מורים מקצועיים, פריטים לחנות, ורשימת הערות להורים.

הנתונים נשמרים במסמך Firebase חדש (`schoolData/singleClass`) ולא נקראים מנתוני הכיתות הישנות.

## חלונית שיעור

במחשב: כפתור «חלונית שיעור» פותח חלון צר עם שיעורי היום בלבד.  
באפליקציה מותקנת / בטלפון: אותו כפתור מצמצם את המסך לשיעורים של היום.
